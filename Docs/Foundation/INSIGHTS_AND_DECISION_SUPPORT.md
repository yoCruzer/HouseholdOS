# Insights and Decision Support

Status: FROZEN AT PRODUCT LEVEL
Version: 1.0

## Principle

HouseholdOS 的洞察必须基于用户自己的事实和明确计算口径，而不是只输出通用消费建议。

## V1 Metrics

在数据可用时提供：

- 持有时长
- 服役时长
- 总支出
- 总回收
- 净投入
- 已记录使用次数
- 单次使用成本
- 日均持有成本
- 日均服役成本
- 最近使用时间
- 维修次数和维修成本

## Unified Formulas

- 总支出 = 初始取得支出 + 后续支出
- 总回收 = 退款 + 赔偿 + 出售收入 + 回收收入
- 净投入 = 总支出 - 总回收
- 持有天数 = 取得日至当前或终止日
- 服役天数 = 首次使用日至当前或终止日
- 单次使用成本 = 净投入 / 已记录使用次数
- 日均持有成本 = 净投入 / 持有天数
- 日均服役成本 = 净投入 / 服役天数

## Data Quality

展示指标时必须说明：

- 金额未知或估算
- 日期精度
- 使用次数是否估算
- 是否存在跨币种
- 是否缺少首次使用或终止事件

不能制造虚假精确感。

## V1 Decision Support

V1 以证据展示为主：

- 长期未使用
- 维修投入高
- 同类重复拥有
- 使用次数低但成本高
- 用户明确写下“不愿再次购买”

## Future AI

未来 AI 建议必须：

- 明确引用具体 Item、事件或心得。
- 将建议与事实分开。
- 允许用户查看依据。
- 不自动删除、购买或改变正式数据。
- 不依赖云端能力才能访问已有记录。

## WishItem Connection

未来 WishItem 可利用：

- 同类物品拥有数量
- 最近使用情况
- 旧物品购买复盘
- 目标预算
- 等待期
- 价格比较

V1 不实现该流程，但不得将其耦合进 Item 持有模型。
