# Privacy and Data Strategy

Status: FROZEN
Version: 1.0

## Local-first Baseline

V1 核心数据、图片、搜索和统计必须可离线工作。

未经单独批准，不引入：

- 第三方账号体系
- 云端 AI
- 外部分析 SDK
- 广告 SDK
- 远程日志上传
- 电商账号连接

## Data Ownership

用户应能够：

- 查看和修改自己的数据。
- 导出结构化数据。
- 备份媒体与数据库。
- 迁移到未来版本。
- 在明确了解影响后删除数据。

不得以订阅限制用户访问或导出已有数据。

## Photo Import Fidelity

导入本地照片时：

- 默认保留原始文件和原始元数据。
- 不默认删除 GPS、拍摄时间或其他 EXIF。
- 不因 UI 不展示某字段而销毁它。
- 本地保留的元数据未来可用于时间、地点或证据场景。

## Export Privacy Policy

普通对外分享与本地完整备份是不同操作。

### Share / External Export

默认：

- 生成派生副本。
- 删除 GPS 和精确定位元数据。
- 不修改原始文件。
- 对序列号、家庭位置、价格、成员身份和敏感凭证采取最小披露。
- 在设置中说明当前行为。

未来可提供：

- 删除定位信息（默认开启）
- 删除全部非必要 EXIF
- 保留原始元数据（需显式选择）
- 选择是否包含价格、位置、序列号等字段

### Full Backup

完整备份以可恢复性为优先：

- 尽可能忠实保留原始媒体和元数据。
- 使用明确的备份格式和版本号。
- 可包含敏感数据时必须给出提示。
- 不应与普通“分享”共用默认策略。

## Sensitive Assets

票据、保修凭证、订单号和序列号属于高敏感信息：

- 默认不出现在公开分享。
- UI 应避免无意暴露。
- 导出时要求明确选择。
- 日志中不得输出原始值。

## Sync

CloudKit 和家庭共享不属于初始 Stage。未来同步设计必须：

- 不破坏本地独立可用。
- 明确冲突和删除语义。
- 保留事件历史。
- 支持失败恢复。
- 不默认将敏感媒体上传到未经批准的服务。

## Telemetry

V1 默认不接入第三方遥测。必要诊断优先使用：

- 本地、最小化日志。
- 不含个人数据。
- 可由用户主动导出。
- Debug 与 Release 行为明确分离。
